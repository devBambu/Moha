# 모하 (Moha)

> 오늘 뭐 하지? 계획하고, 실행하고, 돌아보는 하루.

**모하(Moha)** 는 Daily Scrum의 흐름을 개인의 하루에 적용한 iOS 앱입니다.

단순히 할 일을 기록하는 것에서 끝나지 않고,
**계획 → 실행 → 회고**의 흐름을 통해 하루를 관리하고 돌아볼 수 있도록 만드는 것을 목표로 합니다.

## 주요 기능

* 하루 계획 작성 및 관리
* 계획별 진행 상태 기록
* 하루 회고
* 주간 / 월간 리포트
* 리마인드 알림

## 기술 스택

| Category | Technology |
| --- | --- |
| UI | SwiftUI |
| Architecture | MVI + Router Pattern |
| Persistence | SwiftData |
